# 文件夹加密器（InstantLock）

重新实现的文件夹加密工具。界面尺寸、控件坐标、字号字体、以及右侧栏的可伸缩行为都按
LockDir 7.0.0.95 的窗体资源（DFM）对齐，去掉了广告、倒计时、购买提示和注册限制，
重点做「瞬间加密」。

## 交付文件

- `文件夹加密器.exe` / `build\InstantLock.exe` —— 主程序（单文件，免安装，需 .NET Framework 4.8）
- `build\app.ico`  —— 程序图标
- `src\`           —— 全部源码（C# / WinForms）
- `tests\`         —— 引擎自动化测试
- `tools\`         —— 截图工具、命令行锁定助手

## 右侧栏可伸缩（窗口尺寸随之变化）

加密窗口与解密窗口右侧的「密码提示 / 安全邮箱 / 加密信息」区域可以收起和展开，
对应原版的 `imgbtnExpansion (426,128,13×45)` 与 `imgbtnShrink (736,128,13×45)`：

- 启动时默认是**最小界面**（宽 439，右侧栏收起）；
- 展开状态：窗口宽 750，手柄在 `736,128`（向右箭头），点击收起；
- 收起状态：窗口宽度收缩到 **439**，右侧栏隐藏，手柄移到 `426,128`（向左箭头），点击恢复；
- 关闭按钮（×）始终贴在窗口右上角，收起后依然可见。

和原程序一样，收起后窗口本身会变窄，而不只是隐藏面板；标题栏的「设置」和底部版本号
也会跟着移动到左侧深色区域内，避免压到青色装饰区。

右栏内容做成了一张卡片：左侧一条青色强调线，用钥匙/信封图标分别标注「密码提示」「安全邮箱」，
两个输入框等距排列，底部一行灰色说明「提示与邮箱保存在本机加密文件中」。

## 两种加密方式

**普通（瞬间锁定）** —— 默认。整个过程只做三件不需要搬运数据的事：

1. 把每个文件改名为随机名并移动进隐藏容器 `.ilock\data`（同盘改名，元数据操作）；
2. 只改写每个文件开头的 4KB（AES-256-CTR 流密码异或）；
3. 给容器和文件夹加隐藏 + 系统属性，写入带锁图标的 `desktop.ini`。

耗时只跟文件个数有关，与文件总大小几乎无关。实测 1201 个文件 / 147MB：
加密 1.93 秒，解密 1.96 秒。

**高级（AES-256 完全加密）** —— 对整个文件流式加密，带进度条，可中断，
耗时与数据量成正比（约 10–15 秒 / 100MB）。

## 安全模型（请如实理解）

- 密钥派生：PBKDF2-SHA256，60000 次迭代，16 字节随机盐。
- 文件加密：AES-256-CTR；完整性 HMAC-SHA256（先加密后认证），篡改会被检测并拒绝解密。
- 密码修改只重新包裹密钥文件，不重加密数据 —— 数据密钥（DataKey）与密码解耦。
- **瞬间模式的边界**：只有文件头 4KB 和文件名被加密，剩余数据仍在磁盘上。
  它能阻止在资源管理器里查看、打开、改名绕过，但**不能抵御取证级数据恢复**。
  真正敏感的数据请使用「高级（完全加密）」。
- 没有服务器、没有后门、没有找回密码功能。密码遗忘即数据不可恢复，请务必填写密码提示。

## 使用

1. 把 `文件夹加密器.exe` 放进要加密的文件夹，双击运行 —— **默认就选中它所在的文件夹**，
   也可以点文件夹行右侧的放大镜按钮改选其他文件夹。
2. 输入密码后按 **Tab** 会跳到「再次输入」（也可直接按回车跳到下一格），确认密码后按回车立即加密；
   Tab 顺序是：密码 → 再次输入 → 密码提示 → 安全邮箱 → 加密按钮。
3. 加密过程中**不弹任何确认框或成功提示，完成后程序直接退出**。此时文件夹里会出现隐藏的 `.ilock`
   目录、原文件全部消失。程序自身不会被移进容器，仍留在文件夹里，方便随时解密。
4. 解密：再次双击文件夹里的程序（或加密时自动生成的 `文件夹解密.exe`）——程序检测到本目录
   已加密，会直接打开解密窗口；输入密码**按回车**即开始解密，同样没有弹窗。解密方式：
   - 完全解密：恢复全部文件并删除加密数据；
   - 临时解密：立即恢复文件，可随时一键恢复加密（密钥经 DPAPI 保存在当前用户目录，重加密不需再次输入密码）；
   - 虚拟磁盘：临时解密后用 `subst` 映射一个盘符（内部用硬链接镜像，不额外占用磁盘空间）。

设置窗口提供：加密强度、登录密码、是否复制解密程序、是否显示加密标志、右键菜单集成、
按盘符搜索本机所有被本程序加密的文件夹、修改密码 / 完整性检查。

## 与原版的差异

- 无广告、无倒计时、无购买与注册提示、无「喜欢它」弹窗。
- 去掉了原版的中等强度（打乱文件结构 + 加密文件头）与「通过邮件取回密码」（依赖原厂服务器）。
- 虚拟磁盘用盘符映射实现，不是内核驱动级加密盘；需要内核级透明加密请用 BitLocker / VeraCrypt。

## 构建

```
csc /target:winexe /platform:anycpu /optimize+ /langversion:7.3 ^
    /win32icon:build\app.ico /win32manifest:src\app.manifest ^
    /out:build\InstantLock.exe ^
    /r:System.dll /r:System.Core.dll /r:System.Drawing.dll /r:System.Windows.Forms.dll ^
    src\*.cs
```
